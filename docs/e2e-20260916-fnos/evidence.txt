关键环境准备发现
================
1. 全新 fnOS 必须创建存储空间（否则 install-fpk 报 code 20001 = INSTALL_VOLUME_NOT_FOUND）
2. stor.create API 需要 password 参数（管理员密码二次确认），errno 131072 = E_USER_PASSWD_ERROR
3. 从 0.8.47 升级到 1.2.x 后用户 shell 被重置为 /usr/sbin/nologin，需重新授权 SSH/调整 shell
4. appcenter 的 downloadAndInstallVolumeID 默认可能指向不存在的卷，需校正
